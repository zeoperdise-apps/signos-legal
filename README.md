# signos-legal

Steam向けゲーム『**SIGNOS: AI Robot Builder**』の法務ドキュメントを公開するためのリポジトリです。

静的HTMLのみで構成されており、ビルド手順やフレームワークへの依存はありません。

## 公開ドキュメント

| ドキュメント | ファイル | 言語 |
| --- | --- | --- |
| プライバシーポリシー / Privacy Policy | [`index.html`](index.html) | 日本語・English(併記) |

公開URLは GitHub Pages 有効化後に `https://zeoperdise-apps.github.io/signos-legal/` となります(Settings → Pages → Source: `main` / `/ (root)`)。このURLをSteamストアページのプライバシーポリシー欄に登録します。

## ローカルでの確認

```bash
# 直接開く、または簡易サーバーで確認

```

## 更新時のルール

1. **日本語版と英語版を必ず両方更新する。** 片方だけ修正した状態で公開しない
2. **最終更新日を両方書き換える。** `<p class="updated">` が日英で計2箇所ある
3. 内容に相違が生じた場合、**日本語版が優先**する(ポリシー13章「準拠言語」に明記)
4. 実質的な変更を行った場合は、ポリシー12章の定めどおり、Steamストアページ等で周知する

## ゲーム実装と連動している記述

ポリシー本文では、以下を**事実として断定**しています。ゲーム本体またはサーバー側の仕様を変更した場合、ポリシーの更新が必要です。

| 該当箇所 | 記述している内容 |
| --- | --- |
| 2章 | 広告配信・プロファイリング・自動化された意思決定には利用しない |
| 3章 | 他プレイヤーに公開されるのは、機体構成・AIロジック・ランキング情報のみ |
| 3章 | Steam表示名(ペルソナ名)・アバター画像を他プレイヤーに表示しない |
| 3章 | チャット等の自由入力欄が存在しない |
| 4章 | データ保存先は AWS アジアパシフィック(東京)リージョン(日本国内) |
| 6章 | 期間経過のみを理由とする自動削除は行わない／削除請求には原則30日以内に対応 |
| 8章 | 個人情報の「販売」「共有」を行っていない |

特に **3章のチャット機能・表示名の不存在**は、将来的にソーシャル機能やロボット名の自由入力を追加した際に真っ先に不整合となる箇所です。

## 想定している規制

以下の適用を想定した条項を含んでいます。

- **GDPR**(EEA・英国) — 処理の法的根拠、越境移転(日本の十分性認定)、データ主体の権利、監督機関への苦情申立権
- **CCPA / CPRA**(カリフォルニア州) — 知る権利・削除・訂正・非差別、販売/共有の否認
- **個人情報保護法**(日本)

> 本リポジトリの内容は、公開されている各規制の一般的な要件に基づいて作成したものであり、法的助言ではありません。事業規模や実装内容によっては追加の対応が必要となる場合があります。
